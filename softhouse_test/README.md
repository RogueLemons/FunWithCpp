# How to build
Build with g++ by installing g++ for your system, then writing:

```
g++ main.cpp -o app
```

# How to run
After building, run test data with:

```
.\app -f clean_data.csv   
```

or

```
.\app -f .\data_with_anomalies.csv
```

# Prebuilt
Prebuilt binary available for Windows x86_64, called `app.exe`.
